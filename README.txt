# TUCK Store — starter site

This is a static starter storefront for tuckshop.in.

Included:
- White/minimal TUCK visual theme
- TUCK logo and the three uploaded visuals
- Product categories: T-shirts, Bookmarks, Canvas, Caps
- Responsive mobile layout
- Filterable product grid
- Working demo cart
- Story/newsletter sections
